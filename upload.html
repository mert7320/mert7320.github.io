04 // UPLOAD TO GITHUB
  1. Click [DOWNLOAD UPLOAD PACKAGE]. This saves one .zip containing everything.
  2. Double-click the downloaded zip to extract it. You get a packs/ folder and a packs.json file.
  3. Open github.com/<you>/mert7320.github.io → Add file → Upload files.
  4. Drag the packs folder and the packs.json file into the upload box together. GitHub keeps the folder structure.
  5. Scroll down, type a message like add pack 001, and click Commit changes.
  6. Wait a minute, then visit https://<you>.github.io — your photos appear in the gallery and the pack appears in the archive.
