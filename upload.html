  1. Build the pack above, then download the .zip and packs.json.
  2. Open github.com/<you>/mert7320.github.io in your browser.
  3. Click Add file → Upload files.
  4. Drag the .zip into the packs/ folder. If there is no packs/ folder, type packs/ in the filename box to create it.
  5. Go back, click Add file → Upload files again, and upload the new packs.json to the root (replacing the old one).
  6. Scroll down, write a message like add pack 001, and click Commit changes.
  7. Wait a minute, then visit https://<you>.github.io — the new row appears with a working download button.
